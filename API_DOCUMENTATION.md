## Response Conventions

- Most `/api/*` endpoints return JSON envelopes such as `{"remark":"...","status":"success|error","message":{"success|error":[...]},"data":{...}}`.
- Most `/admin/*` GET routes return HTML Blade views; most mutating admin routes return redirects with flash notifications. Where an admin route is called via JavaScript (`fetch`/AJAX), the response is typically JSON.
- `/ipn/*` endpoints are payment webhooks/callbacks; responses depend on the gateway controller and usually acknowledge or redirect payment state.
